# 服务端部署指南（Docker，零构建）

服务器上不执行任何构建：镜像由 GitHub Actions 在 push 到 `master` 时自动构建并推送到 GHCR，服务器只需 `pull + up`。

## 镜像地址

```
ghcr.io/tsinhzl/codex2cc:latest
```

多架构：`linux/amd64` 与 `linux/arm64`。

## 前置要求

- 任意 Linux 发行版，已安装 Docker（未安装：`curl -fsSL https://get.docker.com | sh`）
- 无需 Go / Node / 源码

## 部署步骤

### 1. 创建项目目录与配置

```bash
mkdir -p ~/codex2cc && cd ~/codex2cc
```

创建 `docker-compose.yml`：

```yaml
services:
  codex2cc:
    image: ghcr.io/tsinhzl/codex2cc:latest
    container_name: codex2cc
    restart: unless-stopped
    ports:
      - "127.0.0.1:8080:8080"
    env_file:
      - .env
    environment:
      DATABASE_DRIVER: sqlite
      DATABASE_PATH: /app/data/codex2cc.db
      CACHE_DRIVER: memory
    volumes:
      - codex2cc-data:/app/data
      - ./logs:/app/logs

volumes:
  codex2cc-data:
```

创建 `.env`（完整变量见仓库 `.env.example`）：

```bash
cat > .env << 'EOF'
CODEX_PORT=8080
ADMIN_SECRET=
DATABASE_DRIVER=sqlite
DATABASE_PATH=/app/data/codex2cc.db
CACHE_DRIVER=memory
EOF
```

`ADMIN_SECRET` 留空则首次访问管理后台时按引导初始化。

### 2. 拉取并启动

```bash
docker compose pull
docker compose up -d
```

GHCR 镜像为 public 时免登录；若设为私有包，先执行 `echo <GITHUB_PAT> | docker login ghcr.io -u <用户名> --password-stdin`。

### 3. 验证

```bash
curl http://127.0.0.1:8080/health     # 期望 200
docker compose logs -f codex2cc
```

### 4. 管理后台与 CLI 接入

端口绑定在 `127.0.0.1`，外部不可直接访问。管理后台通过 SSH 隧道访问：

```bash
ssh -L 8080:127.0.0.1:8080 root@服务器IP
# 本地浏览器打开 http://localhost:8080/admin/
```

按引导设置管理员密钥，添加 Codex OAuth / relay 上游账号并创建 API Key，然后在本机接入：

```bash
export ANTHROPIC_BASE_URL=http://localhost:8080   # SSH 隧道场景；服务器本机用 127.0.0.1，公网用反代后的 https 地址
export ANTHROPIC_AUTH_TOKEN=<API Key>
claude
```

公网使用建议前置 Nginx/Caddy 反代加 TLS 后再对外开放。

## 更新版本

代码合并到 `master` 后，等 GitHub Actions 构建完成（仓库 Actions 页查看），服务器上执行：

```bash
docker compose pull && docker compose up -d
```

数据在 `codex2cc-data` 卷中，更新不丢失；`docker compose down` 也不删卷，仅 `down -v` 会清数据。

## 常用运维命令

- 查看日志：`docker compose logs -f`
- 重启服务：`docker compose restart`
- 停止服务：`docker compose down`
- 备份数据：`docker run --rm -v codex2cc_codex2cc-data:/data alpine tar czf - -C /data . > backup.tgz`
